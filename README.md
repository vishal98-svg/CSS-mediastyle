# Media Query

A responsive web design project demonstrating how CSS media queries adapt a layout to different screen sizes and devices.

## Overview

Media queries let a webpage apply different styles based on conditions such as viewport width. This project is a starting point for practicing responsive design and creating layouts that work across mobile, tablet, and desktop screens.

## Features

- Responsive styling with CSS media queries
- A mobile-first approach can be used as the project grows
- Simple foundation for experimenting with breakpoints and layout changes

## Getting Started

1. Clone or download this repository.
2. Open the project files in your code editor.
3. Open the HTML file in a browser, or run it with your preferred local development server.
4. Resize the browser window to see responsive styles take effect.
